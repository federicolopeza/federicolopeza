## How I work: the limit is *part of the design*

1. **Who can act?** Explicit permissions, and human approval for sensitive actions.
2. **What stops it?** Limits set by the operator, not by the automation.
3. **Can you explain the decision?** Traceability, reproducible evidence and a recorded reason.

I work with tests, documentation, traceability and agreed acceptance criteria.
